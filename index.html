1️⃣
Introducción al Deep Learning

📌 Definición

Deep Learning es un subcampo del Machine Learning que permite a las computadoras aprender representaciones de datos con múltiples niveles de abstracción usando redes neuronales profundas.

✨ Factores Clave del Éxito

📊 Mayor Disponibilidad de Datos

Internet, redes sociales, sensores IoT generan cantidades masivas de datos disponibles para entrenar modelos complejos.

⚡ Mejora de Capacidad de Cómputo

GPUs permiten entrenar redes profundas en tiempo razonable, acelerando cálculos matriciales masivos.

🔧 Mejoras Algorítmicas

Dropout, Batch Normalization, ReLU y nuevas técnicas de optimización mejoraron significativamente el entrenamiento.

🚀 Aplicaciones Exitosas

Principales Áreas de Aplicación

  • Visión por computador: Reconocimiento facial, detección de objetos, segmentación
  • Procesamiento de lenguaje natural: Traducción automática, análisis de sentimientos, chatbots
  • Reconocimiento del habla: Asistentes virtuales (Siri, Alexa, Google Assistant)
  • Aprendizaje por refuerzo: AlphaGo venció al campeón mundial de Go

🧠 Componentes de una Red Neuronal

Neurona Artificial

Unidad básica que recibe inputs, aplica pesos, suma, agrega bias y aplica función de activación: y = f(Σwᵢxᵢ + b)

Pesos (Weights)

Parámetros que se aprenden durante el entrenamiento, determinan la importancia de cada input

Bias

Término independiente que permite desplazar la función de activación

Función de Activación

Introduce no-linealidad: sigmoid, tanh, ReLU

🎯 Punto Clave: Las redes neuronales se inspiran en el cerebro pero con diferencias significativas. La función de activación es crucial para permitir que la red aprenda patrones no lineales.

2️⃣
Entrenamiento de Redes Neuronales

📌 Objetivo del Entrenamiento

Ajustar pesos y biases para minimizar una función de pérdida (loss function) que mide la diferencia entre predicciones y valores reales.

🔄 Backpropagation

Algoritmo Fundamental

• Calcula gradientes de la función de pérdida respecto a cada peso
• Usa la regla de la cadena para propagar el error desde la salida hacia capas anteriores
• Permite actualizar eficientemente todos los pesos de la red

📉 Gradient Descent

Batch GD

Usa TODO el dataset en cada iteración. Lento para datasets grandes pero convergencia suave.

Stochastic GD (SGD)

Usa UN ejemplo a la vez. Rápido pero ruidoso, convergencia errática.

Mini-batch GD ⭐

Compromiso óptimo. Batch sizes típicos: 32, 64, 128, 256. El MÁS USADO.

⚙️ Learning Rate

🎯 HIPERPARÁMETRO MÁS IMPORTANTE:
• Muy alto → divergencia, saltos erráticos
• Muy bajo → convergencia lenta, mínimos locales
• Valores típicos: 0.001, 0.0001, 0.00001

🚀 Optimizadores Avanzados

Momentum

Acumula velocidad en direcciones consistentes del gradiente, acelera convergencia

RMSprop

Adapta learning rate por parámetro usando promedio móvil de gradientes al cuadrado

Adam ⭐⭐⭐

Combina Momentum y RMSprop. El MÁS USADO. Parámetros: lr=0.001, β₁=0.9, β₂=0.999

AdaGrad

Adapta learning rate basado en frecuencia de actualizaciones

📊 Funciones de Pérdida

MSE (Regresión)

Mean Squared Error - Penaliza errores grandes cuadráticamente

Cross-Entropy (Clasificación)

Mide divergencia entre distribuciones de probabilidad

Binary Cross-Entropy

Para clasificación binaria (2 clases)

Categorical Cross-Entropy

Para clasificación multiclase

🛡️ Regularización - Prevenir Overfitting

Técnicas de Regularización

  • L1 (Lasso): Penaliza suma de valores absolutos, induce sparsity
  • L2 (Ridge): Penaliza suma de cuadrados, mantiene pesos pequeños
  • Dropout: Apaga neuronas aleatoriamente (p=0.5), fuerza redundancia
  • Early Stopping: Detener cuando error de validación aumenta
  • Data Augmentation: Aumentar datos artificialmente (rotaciones, flips)
📚 División de Datos: Training (70-80%), Validation (10-15%), Test (10-15%). ¡Nunca usar test set durante entrenamiento!

3️⃣
Frameworks de Deep Learning

📌 ¿Por qué usar Frameworks?

Proveen APIs de alto nivel, cálculo automático de gradientes, optimización y soporte para GPUs. Evitan errores y aceleran desarrollo.

🔥 Principales Frameworks

🟦 TensorFlow

• Google Brain (2015)
• Grafo estático → dinámico (TF 2.x)
• Excelente para PRODUCCIÓN
• Ecosystem: Serving, Lite, .js

🔶 Keras

• API de alto nivel simple
• Integrada en TensorFlow (tf.keras)
• Ideal para PROTOTIPADO rápido
• Perfecto para principiantes

🔥 PyTorch ⭐

• Facebook AI (2016)
• Grafos DINÁMICOS (define-by-run)
• Preferido en INVESTIGACIÓN
• Sintaxis pythonic

⚡ Otros

• Caffe: Visión rápida
• MXNet: Amazon
• JAX: Google research

⚖️ TensorFlow vs PyTorch:
• TensorFlow: Mejor para producción, ecosistema maduro
• PyTorch: Mejor para investigación, más flexible, debugging más simple

4️⃣
Aspectos Prácticos del Entrenamiento

⚡ Funciones de Activación

Sigmoid

Output [0,1]. Problema: Vanishing gradient. NO recomendada para capas ocultas

Tanh

Output [-1,1]. Mejor que sigmoid pero aún vanishing gradient

ReLU ⭐⭐⭐

f(x)=max(0,x). La MÁS USADA. Simple, rápida, no satura. Problema: Dying ReLU

Leaky ReLU

f(x)=max(0.01x,x). Soluciona dying ReLU

ELU

Suaviza negativos exponencialmente. Media cercana a cero

Maxout

Generaliza ReLU. Más parámetros pero más expresiva

🎲 Inicialización de Pesos

Xavier/Glorot

Diseñada para sigmoid/tanh. Mantiene varianza constante entre capas

He Initialization ⭐

Óptima para ReLU. Considera que ReLU mata mitad de neuronas

📊 Batch Normalization

🚀 Beneficios:
• Acelera DRAMÁTICAMENTE el entrenamiento
• Permite learning rates más altos
• Reduce sensibilidad a inicialización
• Actúa como regularización
• Normaliza activaciones por mini-batch

🔄 Transfer Learning

Reutilizar Modelos Pre-entrenados

• Feature extraction: Congelar capas convolucionales, entrenar solo finales
• Fine-tuning: Entrenar también algunas conv con LR bajo
• Reduce tiempo y datos necesarios

5️⃣
Convolutional Neural Networks (CNN)

📌 ¿Por qué CNNs?

Redes fully connected tienen DEMASIADOS parámetros para imágenes. CNNs explotan estructura espacial y comparten parámetros → reducción dramática.

🔍 Componentes Clave

Capa Convolucional

Filtros (kernels) se deslizan sobre imagen. Detectan patrones (bordes, texturas, formas). Kernels típicos: 3x3, 5x5

Pooling (Max Pooling)

Reduce dimensionalidad espacial. Toma valor máximo de cada región. Da invarianza a traslaciones

Arquitectura Típica

CONV→ReLU→POOL→CONV→ReLU→POOL→...→Flatten→FC→Output

🏗️ Arquitecturas Famosas

Evolución de CNNs

  • LeNet-5 (1998): Primera CNN exitosa, dígitos 32x32
  • AlexNet (2012): Ganó ImageNet, marcó inicio era DL. 8 capas, ReLU, Dropout
  • VGG (2014): Muy profunda (16-19), solo kernels 3x3. 138M parámetros
  • GoogLeNet/Inception (2014): Módulos Inception paralelos. 22 capas, solo 5M params
  • ResNet (2015): Skip connections, 50-152 capas. Una de las MÁS INFLUYENTES
  • MobileNet: Para móviles, depthwise separable convolutions
  • EfficientNet (2019): Estado del arte en eficiencia
🎯 ResNet: Las skip connections previenen vanishing gradient y permiten entrenar redes MUY profundas (hasta 1000 capas)

📱 Aplicaciones

Clasificación

Asignar etiqueta a imagen completa

Detección

YOLO, Faster R-CNN - localizar objetos

Segmentación

U-Net, Mask R-CNN - píxel a píxel

Medicina

Detección tumores, clasificación rayos X

6️⃣
Word Vectors (Embeddings)

📌 Problema

Las computadoras no entienden palabras directamente. Necesitamos representarlas como números.

🔢 One-Hot Encoding

Representación Simple pero Limitada

• Vector con 1 en posición de palabra, 0 en resto
• Problemas: Alta dimensión (=vocab size), sparse, NO captura similaridad semántica
• 'perro' y 'gato' son igual de diferentes que 'perro' y 'avión'

✨ Word Embeddings

💡 Solución: Representaciones densas de baja dimensión (50-300) que capturan relaciones semánticas. Palabras similares → vectores cercanos

🔤 Word2Vec

Skip-gram

Predice palabras de contexto dada palabra central. Mejor para datasets pequeños y palabras raras

CBOW

Predice palabra central dado contexto. Más rápido que skip-gram

🎯 Propiedad Notable

Captura analogías mediante aritmética vectorial:
• king - man + woman ≈ queen
• Paris - France + Italy ≈ Rome
• walking - walk + swim ≈ swimming

🌍 GloVe (Global Vectors)

Stanford 2014

Factoriza matriz de co-ocurrencia global. Combina métodos globales y locales. Supera Word2Vec en analogías

⚡ FastText

Facebook AI

Extensión de Word2Vec considerando sub-palabras (n-gramas). Genera embeddings para palabras OOV (fuera de vocabulario)

🆕 Embeddings Contextuales: Word2Vec/GloVe dan UN vector por palabra. ELMo, BERT generan vectores diferentes según contexto ('banco' financiero vs 'banco' de peces)

7️⃣
Recurrent Neural Networks (RNN)

📌 ¿Por qué RNNs?

Redes feedforward no manejan bien datos secuenciales (texto, series temporales, audio). RNNs tienen conexiones recurrentes que permiten 'memoria'.

🔄 Arquitectura RNN Básica

Estado Oculto

• h_t = f(W_hh * h_{t-1} + W_xh * x_t + b)
• Mismo conjunto de pesos compartido en todos los pasos
• Procesa secuencias de longitud variable

⚠️ Problema: Vanishing Gradient

🔴 En secuencias largas: Gradientes se vuelven exponencialmente pequeños. La red 'olvida' información lejana. RNN vanilla no captura dependencias de largo plazo.

🔐 LSTM (Long Short-Term Memory)

Solución al Vanishing Gradient (1997)

  • Cell state (C_t): 'Cinta transportadora' para información largo plazo
  • Forget gate: Decide qué desechar del cell state
  • Input gate: Decide qué nueva información agregar
  • Output gate: Decide qué mostrar como output

✅ LSTM puede aprender dependencias de MUCHO más largo plazo que RNN vanilla

⚡ GRU (Gated Recurrent Unit)

Variante Simplificada (2014)

• Solo 2 gates: reset y update
• Menos parámetros → más rápido
• Performance similar a LSTM

↔️ Bidirectional RNNs

Contexto Pasado Y Futuro

Procesa secuencia en AMBAS direcciones. Útil cuando toda la secuencia está disponible (traducción, clasificación)

📱 Aplicaciones

NLP

Traducción, análisis sentimientos, generación texto

Speech

Reconocimiento de voz

Series Temporales

Predicción stocks, clima

Image Captioning

Descripción automática de imágenes

⚠️ Limitación: Procesamiento secuencial NO paralelizable → lento. Transformers (attention) están reemplazando RNNs en NLP

8️⃣
Deep Reinforcement Learning

📌 ¿Qué es RL?

Un agente aprende a tomar decisiones mediante interacción con un entorno, recibiendo recompensas o penalizaciones.

🧩 Componentes Fundamentales

Agente

El que toma decisiones

Entorno

Mundo con el que interactúa

Estado (s)

Situación actual del entorno

Acción (a)

Decisión tomada por agente

Recompensa (r)

Feedback positivo o negativo

Política (π)

Estrategia: mapea estados → acciones

🎯 Objetivo: Maximizar recompensa acumulada TOTAL a largo plazo, no solo inmediata

⚖️ Exploración vs Explotación

Dilema Fundamental

• Exploración: Probar acciones nuevas para descubrir mejores estrategias
• Explotación: Usar conocimiento actual para maximizar recompensa
• Equilibrar ambas para aprender eficientemente

🎮 DQN (Deep Q-Network)

DeepMind 2015 - Innovaciones Clave

  • Combina Q-Learning con Deep Learning
  • Red neuronal aproxima Q(s,a) en lugar de tabla
  • Experience Replay: Memoria de transiciones, mini-batches aleatorios
  • Target Network: Red separada para calcular targets → estabilidad
  • Maneja espacios de estados ENORMES (píxeles de videojuegos)

🎭 Policy Gradients

Aprende Política Directamente

• Aprende π(a|s) en lugar de Q(s,a)
• Maneja espacios de acciones continuos
• Algoritmos: REINFORCE, Actor-Critic, PPO, A3C

🎪 Actor-Critic

Híbrido Value + Policy

• Actor: Aprende política
• Critic: Evalúa acción tomada
• Reduce varianza de policy gradients

🏆 Casos de Éxito

AlphaGo

Venció campeón Go (2016). Deep RL + Monte Carlo + CNNs

AlphaZero

Aprende desde cero ajedrez, Go, shogi en horas

DQN Atari

Superó humanos en 49 juegos usando solo píxeles

Robótica

Control de robots, manipulación de objetos

9️⃣
Redes Neuronales en Big Data

📌 Desafíos

• Datasets de TB/PB que NO caben en memoria
• Tiempo de entrenamiento prohibitivo en un solo device
• Necesidad de procesamiento distribuido

⚡ Apache Spark

Framework de Procesamiento Distribuido

• Procesamiento en memoria
• 100x más rápido que Hadoop MapReduce
• APIs: Scala, Java, Python, R
• Componentes: Spark SQL, MLlib, GraphX, Streaming

🔀 Paralelismo de Datos (Data Parallelism)

⭐ Estrategia MÁS COMÚN:
• Cada worker tiene COPIA COMPLETA del modelo
• Datos se dividen entre workers
• Cada worker calcula gradientes en su subset
• Gradientes se agregan (promedio/suma) para actualizar modelo

Síncrona

Espera a todos los workers. Más estable pero puede ser lenta

Asíncrona

Workers actualizan independientemente. Más rápida pero inestable

🧩 Paralelismo de Modelo (Model Parallelism)

Para Modelos MUY Grandes

• Modelo se DIVIDE entre workers
• Útil cuando modelo no cabe en un device
• Más complejo que data parallelism
• Mayor comunicación entre workers

🛠️ Frameworks Distribuidos

Horovod

Uber. Simplifica data parallelism. TF, Keras, PyTorch, MXNet

TensorFlowOnSpark

Integra TensorFlow con Spark

Ray

Apps distribuidas. Incluye RLlib y Tune

⚙️ Consideraciones Prácticas

• Batch size efectivo = batch_per_worker × num_workers
• Learning rate: Linear scaling rule al escalar
• Comunicación: InfiniBand o NVLink
• Gradient compression para ahorrar ancho de banda

Ecosistemas en la Nube y Producción

🔄 Ciclo de Vida ML

7 Etapas

  • 1. Definición del problema y objetivos

  • 3. Preparación (limpieza, feature engineering)
  • 4. Entrenamiento y experimentación

🔧 MLOps

DevOps para ML

• Versionado: Código, datos, modelos (DVC, Git LFS)
• CI/CD: Integración y deployment continuo
• Monitoreo: Performance, data drift, model drift
• Reproducibilidad: Experimentos replicables

🐳 Docker

Containerización

• Empaqueta app + dependencias en contenedor portable
• Garantiza mismo comportamiento en dev, test, producción
• Dockerfile define imagen
• Docker Compose para múltiples contenedores

☸️ Kubernetes

Orquestación de Contenedores

• Auto-scaling basado en carga
• Self-healing: reinicia contenedores fallidos
• Load balancing automático

🚀 Serving de Modelos

TensorFlow Serving

Sistema flexible y rápido. REST API o gRPC. Versionado de modelos

TorchServe

Equivalente para PyTorch. APIs REST y gRPC. Métricas integradas

ONNX Runtime

Formato abierto. Convierte entre frameworks. Optimizado para inferencia

Últimos Avances en Deep Learning

🤖 Transformers

'Attention is All You Need' (2017)

• Basado COMPLETAMENTE en attention (sin recurrencia)
• Paralelización TOTAL (vs RNN)
• Captura dependencias largo alcance
• Self-Attention: cada palabra 'atiende' a todas las demás
• Multi-head attention: múltiples representaciones paralelas

📚 BERT

Google 2018 - Bidireccional

  • Pre-entrena BIDIRECCIONAL (contexto izq Y der)
  • Masked Language Model: Predice palabras enmascaradas
  • Next Sentence Prediction: Oraciones consecutivas
  • Fine-tuning para tareas específicas
  • Revolucionó NLP: estado del arte en 11 tareas

💬 GPT (Generative Pre-trained Transformer)

GPT-1 (2018)

Decoder autoregresivo. Pre-train + fine-tune

GPT-2 (2019)

1.5B parámetros. Texto coherente. Zero-shot learning

GPT-3 (2020) ⭐

175B parámetros. Few-shot (5-10 ejemplos). Traducción, código, razonamiento

ChatGPT/GPT-4

RLHF. Conversacional. GPT-4 multimodal (texto+imagen)

🎨 GANs (Generative Adversarial Networks)

Ian Goodfellow 2014

• Generator (G): Genera datos falsos
• Discriminator (D): Distingue real vs falso
• Entrenamiento adversarial: juego minimax
• Variantes: DCGAN, StyleGAN, BigGAN

Generación Imágenes

Rostros, paisajes realistas

Style Transfer

Transferencia de estilo artístico

Image-to-Image

CycleGAN, pix2pix

Super-Resolution

Mejorar resolución

👁️ Vision Transformers (ViT)

Transformers para Imágenes (2020)

• Divide imagen en patches (16x16)
• Trata patches como 'palabras'
• Rivaliza o supera CNNs
• Requiere MÁS datos que CNNs

🆕 Otros Avances

Self-Supervised Learning

Aprende sin etiquetas humanas. SimCLR, MoCo

Few/Zero-Shot

Aprender con pocos/sin ejemplos específicos

Modelos Multimodales

CLIP (visión+lenguaje), DALL-E (texto→imagen)

NAS

Neural Architecture Search. Diseño automático
